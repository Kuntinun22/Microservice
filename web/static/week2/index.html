ข่าว1 คดีเงินบริจาค "บุ๋ม ปนัดดา" และมูลนิธิองค์กรทำดี

: ยังเป็นประเด็นร้อนต่อเนื่องหลังมีการตรวจสอบเส้นทางการเงินและประเด็นการนำเงินบริจาคไปใช้ โดยมีกระแสวิพากษ์วิจารณ์และท่าทีจากหลายฝ่าย รวมถึงการสอบสวนข้อเท็จจริง

ข่าว2 การเมืองและการตรวจสอบ

: สำนักนายกรัฐมนตรีทำหนังสือสอบถาม กกต. ปมรับบริจาคน้ำท่วมโยง “พรรคประชาชน” ขณะที่กลุ่มมวลชนเตรียมเคลื่อนไหว โดย "กำนันมะโน" เตรียมนำมวลชนกดดันกระทรวงพลังงานในวันที่ 16 พฤศจิกายนนี้

ข่าว3 ประกาศกรมอุตุนิยมวิทยา

: ภาคใต้ยังมีฝนตกหนักบางแห่ง (เฝ้าระวังน้ำท่วมฉับพลันในหลายจังหวัด) ขณะที่ไทยตอนบนอุณหภูมิสูงขึ้นเล็กน้อยหลังจากลมหนาวพักยก
